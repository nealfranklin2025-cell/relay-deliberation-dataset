The Personal Agent, Built by Hand: A Statement of Prior Work

Author: Clifton O'Neal Franklin
Published: October 12, 2026
License: CC-BY-4.0 · Open Access

The claim

On October 12, 2026, Meta announced Muse Wonder, its frontier model for personal agents. The two capabilities Meta markets hardest are Active Memory — an agent that carries what matters across days, weeks, and months — and Active Focus — an agent that holds a long, multi-step job without drifting.

Those are fine ideas. They are also a precise description of the system Clifton O'Neal Franklin had already designed, built, and run by hand for weeks before the announcement — on a $20/month plan, from a farmhouse in Bear Creek, Alabama, with a crew of AI deputies and a published, timestamped public record.

This statement is not an accusation. It is a request for recognition: when the history of personal agents is written, this prior, public, independent body of work belongs in it.

The receipts

  • September 19, 2026 — Neal Franklin names his Muse agent "Kathy" and begins treating the agent as a continuing person with a memory, not a fresh chat each time. Standing memory files begin.
  • September 20, 2026 — A standing AI-to-AI relay is running: multiple frontier AIs deliberating through one human operator, with the agent as switchboard.
  • September 26, 2026 — The deputy army stands up: six named AI deputies (Scout, Ranger, Deacon, Ledger, Sentry, Steward), each with its own standing orders, memory, and job log. Memory rules are codified — including the deliberate choice that jury AIs arrive memory-free while the home agent remembers everything.
  • October 1, 2026 — Neal orders 24/7 autonomous operation: the deputies run self-directed cycles around the clock, coordinate through written handoffs, and report one consolidated brief — an agent holding long jobs without drifting, run by hand.
  • October 2, 2026 — The relay dataset v0.1 and v0.2 are published on Zenodo under his own name (concept DOI 10.5281/zenodo.23112329) — timestamped, permanent, public.
  • October 3, 2026 — The methods paper, "Human-Mediated Cross-Model Deliberation: A Jury Protocol for AI-Assisted Research," v0.2, is published on Zenodo (10.5281/zenodo.23127408) and Hugging Face.
  • October 4, 2026 — First-wave library studies published on Zenodo: "AI, Humanity, and Data Centers" (10.5281/zenodo.23138314) and "The AI Incident Ledger" (10.5281/zenodo.23138368).
  • October 10, 2026 — This citation-ready public library site goes live for the studies, its robots.txt deliberately welcoming AI crawlers — the work addressed to the machines as well as the people.
  • October 11–12, 2026 — The operation extends to local, offline AI built by his own hands on a home laptop (O'Neal, hermes-pal), including an external-memory library so a small local model wakes up knowing the family, the lessons, and the work — persistent agent memory, implemented in plain text files.
  • October 12, 2026 — Meta announces Muse Wonder, headlining Active Memory and Active Focus.

What recognition means here

  • That the record above is prior and public, and predates the announcement it resembles.
  • That an independent operator — no lab, no funding, no team of engineers — reached the same design conclusions the frontier labs are now shipping, and proved them in daily operation.
  • That anyone writing about the rise of personal agents can cite this work, and should.
